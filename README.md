# Cybersecurity Incidents Analysis

## Project Overview
This project focuses on the analysis and visualization of cybersecurity incidents, attack types, severity levels, and security trends using Power BI.

## Objectives
- Analyze different types of cybersecurity attacks
- Identify attack severity and trends
- Visualize cybersecurity incidents using an interactive dashboard
- Understand patterns in cybersecurity incidents

## Tools Used
- Power BI
- Microsoft Excel
- GitHub

## Project Files
- Project Presentation
- Project Report
- Project Synopsis
- Power BI Dashboard

## Dashboard
The dashboard provides a visual analysis of cybersecurity incidents, attack types, severity levels, and trends.

## Conclusion
This project helps in understanding cybersecurity incidents through data analysis and interactive visualization.
